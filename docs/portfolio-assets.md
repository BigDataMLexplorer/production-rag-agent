# Portfolio asset plan

The Upwork portfolio item should use real outputs from the running demo rather than mock claims.

## Recommended screenshots

1. **Hero / chat screenshot** — `/demo` showing a current-policy answer with visible source/version citation.
2. **Architecture diagram** — Mermaid diagram from `docs/architecture.md`, exported to PNG/SVG.
3. **Evaluation chart** — generated by `scripts/plot_retrieval_evaluation.py` from measured retrieval results.
4. **Human escalation** — reviewable chat paused because evidence is insufficient or unsafe.
5. **Trace screenshot** — OpenTelemetry trace showing retrieval → reranking → generation/tool steps.

## Loom flow (later)

Keep it short and proof-oriented:

- show the synthetic stale/current policy pair,
- ask the retention question,
- show the current version being cited,
- switch tenant and show isolation,
- show one human-escalation case,
- finish on the evaluation chart and architecture diagram.
